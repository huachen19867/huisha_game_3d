# 回煞 3D：归门与余温

2026-11-16，按老板最新指令停止 2D 研发，独立推进第一人称 3D 版本。此文件取代旧的“2D 旁挂 3D 原型”方案。原 2D 工作区和素材原件保留。

## 本次交付

老板进一步明确旧 3D 效果不能接受，本次重新制作，旧原型不作为成品基础。保留 Three.js r160 和可用的原始木材素材，重写全部场景、布局、调查、控制、存档与界面；下载 Poly Haven CC0 中式家具真实 glTF 模型和 PBR 材质，替换旧几何家具/照片贴片。建立独立入口、代码、存档、启动脚本和 Git 历史。原仓库 `huachen19867/huisha_game_AI` 标明 2D 封存；3D 发布到 `huachen19867/huisha_game_3d`。不重命名或强推原远端，不在两边混传运行代码。

第一章围绕正厅和走廊完成一个可重玩的解谜闭环。来信交代回宅动机；调查棺上刻痕、相框背字与门锁说明，回查记录，按实际线索转动三枚字轮，开门后主动选择跨过门槛或暂留。允许猜锁、错误免费重试、成功后继续观察。三字答案不由已读数量自动判定。物件需要在视线方向、可达距离内，墙和家具遮挡有效。

第二段“余温”接在第一扇门外，沿实际连通的石路进入雨庭与右侧厨房，不通过剧情弹窗传送。旧井和灶旁校秤纸指向三升/五升提桶；添水、倒空、互倒改变真实水位，五升桶中恰好四升并主动放上秤盘，才释放桌下抽屉和院门。母亲未寄出的家书与复诊单说明病情早于离家，玩家可带信走向山路，也可主动选择今晚留下。量水成功、读取家书或走到出口均不自动选结局。旧首章存档保留，新增字段用安全默认值扩展，不读取 2D 存档。

厨房柜边的相册可主动翻入“录取那年 / 病历之前 / 雨夜归途”。三处是可行走和返回的独立 3D 空间，复用已有材质，新增 Poly Haven CC0 实体课桌、学校椅子和轮椅。学校核对录取通知与父亲回执，医院核对早于离家的初诊与母亲签字的治疗安排，事故山路核对旧手机录音与今夜的救护交接单。每段均需玩家从已读记录里选两份原文和一个解释后提交；错误保留草稿，读完不自动解开，成功不自动返回。三段核对后，事故场景救护灯前可主动选择“破茧 / 回煞”；原山路的“归路 / 余温”仍保留。记忆门边和暂停均可随时返回厨房，不强制按固定顺序完成。

场景使用中式圈椅、条案和木柜的真实模型，木地板/旧灰墙接入颜色、法线和粗糙度材质。棺木、香炉、门框、窗棂与字轮使用可绕看的实体结构；线索牌以局部文字贴图附在真实器物上。亮度保证路径和关键物件可辨。重做键鼠控制、碰撞子步进、阅读暂停、存档与返回标题，提供触屏移动和调查。

## 实施与验证边界

0.15.0 在近看内展示纸张/手机当前已读原文，避免每读一面都被全文弹窗打断。继续主动记下，不补未知内容或自动判断；摘记/整理复用现有入口，放大阅读保留原模态。未读/侧面与离开会清掉旧原文，记下即保存真实玩家位置。共享原生 details 与既有按钮，不引入新状态/框架；只做相关 DOM 事件回归，不把流程检查当作布局和 WebGL 验收。

0.14.0 把推理判断限定为当前原文能够支持或反驳的事实，不以孝顺、原谅或“留下就能治好”评分。医院初诊和复诊纸张复用 ThreeDocument，分别在桌上平放和立板前放置，放回恢复原朝向；requiredFaces 明确只读哪些面即可核对，病历后续记录可选读。问题更新不把旧选择强套到新措辞：保留旧选证/时间线，提示重选，已完成判断与结局继续有效。0.13 已有学校字段的旧医院整份观察也迁移兼容；检查不代表实机字迹、材质或输入验收。

0.13.0 让学校原文中的“背面”成为实际观察动作。两张纸共用 ThreeDocument，分离受光正反面并可拖动、翻转、主动阅读；日期与留言分别收录，未读日期不生成事实，学校判断须核对所需留言。documentViews 与旧整份记录兼容，阅读/手记/地图回返保留朝向，退出恢复纸张/玩家，原稿内容与解释索引保持。复用相框近看和已有 Three.js，不引入文档引擎或下载纸张图片；检查不代表真实字体、WebGL 或操作验收。

0.12.0 将事故手机改为可拿近、点屏切页和放回的实体物件。通话与本地录音分别主动阅读，phoneViews 保存每页观察；手记和时间线只呈现已有页面，原手机记录 id 与两份选证方式保留，旧整份记录迁移为两页已读。两页均读不自动作出判断。ThreePhone 沿用现有近看生命周期和原始玩家站位，页面绘制仅在切换时更新，不新增在线接口或语音生成。取景/点击数学与 DOM 事件检查不等于屏幕像素或 WebGL 验收。

0.11.0 处理建筑空间的明确缺口：原窗条和暗板背后有整面墙，现用四段墙围出实际窗洞，补实体框、窗台与不同用途的玻璃。老宅窗外增加可观察的侧院深度，既有 walkable 和剧情门槛不变。共用 ThreeWindowWall 建模、连续墙面 UV 与已下载 BufferGeometryUtils 的静态合并，不另建引擎、扩章节或增加材质贴图。几何射线能证明窗洞和边界，不能证明最终光照或玻璃观感。

0.10.0 将量水的“试称”做成可观察的过程：桶提起、上秤、指针指向轻重、失败放回。判断延后到落秤时，正确四升才开始抽屉与铜索释放。操作中保留水量且不接受添/倒/换桶，阅读冻结，离开近看取消临时试称，已经成立的解锁不撤销；减少动态效果和旧存档继续有效。复用已有 Three.js 几何、MathUtils.lerp 和门闩动画的缓入缓出方法，不新增依赖或模型。真实观感仍须实机证据。

0.9.0 把原文的日期、签字与旧语音拆成可排列片段，由玩家主动建立从早到晚的时间线。候选片段来自当前两份已读选证，没有明确日期的描述可留旁；换选证和失败保留顺序，旧已完成判断不要求重做。ThreeMemoryTimeline 使用原生按钮，上下调整不依赖拖动或鼠标；沿用已有 Ink/W3C 参考，不增加叙事运行库。阅读层打开时保存真实玩家站位，避免长时间整理时刷新退回旧位置。Node/DOM 检查不覆盖实际布局与 WebGL。

0.8.0 增加随探索形成的地图，使用现有可走区域几何，不引入预先展开的完整地图。走过和已观察的地点入图，未知器物不标点，不显示“还剩几件”或“房间已搜完”。已知机关/相框/推理状态只取当前故事事实；可回查已读原文和放大已到过的房间，不传送、补观察或自动解谜。近看时用真实站位，记忆和老宅各自显示，旧存档仅从已有观察补回地点。

0.7.0 继续让机关因果在空间中可观察：归门先退闩、落绳再开门，红绳留在地面；厨房铜索和滑轮实体连接量水桌与院门，门闩退出后再开门。家书随抽屉移动，实际露出后才能调查，抽屉的碰撞和玩家站位同步处理。暂停冻结释放过程，存档/重开/减少动态效果恢复一致的完成或初始姿态，不因回看重复播放机关声。

0.6.0 把相框从阅读弹窗改为可拿近、揭布、拖动和翻面的实体物件。揭布仅显示虚构旧照，背字须转到眼前后主动阅读才入手记；新存档区分“已揭布”和“背字已读”，旧存档保留此前的记录。阅读/手记不会重置持物朝向，放回恢复物件、玩家和投影。继续让环境线索承担实际观察动作，避免只用弹窗代替探索。

2026-11-17 的持续优化先减少记忆负担：手记按地点和当前记忆筛选，只呈现已读记录；允许主动摘取两份原文并排对照，在字轮/量水桌旁展开全文，并明确选择是否放入推理草稿。选取与提交分开，摘记不决定解释、不替玩家完成机关；存档兼容旧字段，重开清理摘记。后续继续处理探索反馈与操作问题，不等待老板抽时间试玩才推进能够独立改进的部分。

先隔离仓库并记录来源，再实现调查/机关/终点与场景反馈，最后运行有针对性的 Node 状态、几何可达性和静态依赖检查，核对 GitHub 远端提交。此前浏览器启动被自动审批拒绝，不重试或绕过；本轮不能声称真实 WebGL、触屏或完整实玩已验收。

当前 3D 有老宅两段探索、三处记忆空间和四种主动结局。记忆链重新围绕 3D 场景和新原文制作，不声称 2D 全部地图与追逐已迁移，也不把当前逻辑检查当成美术或实机完整通关验收。后续内容见 ROADMAP；不继续扩写 2D。

# 回煞 3D：归门与余温

2026-11-16，按老板最新指令停止 2D 研发，独立推进第一人称 3D 版本。此文件取代旧的“2D 旁挂 3D 原型”方案。原 2D 工作区和素材原件保留。

## 本次交付

老板进一步明确旧 3D 效果不能接受，本次重新制作，旧原型不作为成品基础。保留 Three.js r160 和可用的原始木材素材，重写全部场景、布局、调查、控制、存档与界面；下载 Poly Haven CC0 中式家具真实 glTF 模型和 PBR 材质，替换旧几何家具/照片贴片。建立独立入口、代码、存档、启动脚本和 Git 历史。原仓库 `huachen19867/huisha_game_AI` 标明 2D 封存；3D 发布到 `huachen19867/huisha_game_3d`。不重命名或强推原远端，不在两边混传运行代码。

第一章围绕正厅和走廊完成一个可重玩的解谜闭环。来信交代回宅动机；调查棺上刻痕、相框背字与门锁说明，回查记录，按实际线索转动三枚字轮，开门后主动选择跨过门槛或暂留。允许猜锁、错误免费重试、成功后继续观察。三字答案不由已读数量自动判定。物件需要在视线方向、可达距离内，墙和家具遮挡有效。

第二段“余温”接在第一扇门外，沿实际连通的石路进入雨庭与右侧厨房，不通过剧情弹窗传送。旧井和灶旁校秤纸指向三升/五升提桶；添水、倒空、互倒改变真实水位，五升桶中恰好四升并主动放上秤盘，才释放桌下抽屉和院门。母亲未寄出的家书与复诊单说明病情早于离家，玩家可带信走向山路，也可主动选择今晚留下。量水成功、读取家书或走到出口均不自动选结局。旧首章存档保留，新增字段用安全默认值扩展，不读取 2D 存档。

场景使用中式圈椅、条案和木柜的真实模型，木地板/旧灰墙接入颜色、法线和粗糙度材质。棺木、香炉、门框、窗棂与字轮使用可绕看的实体结构；线索牌以局部文字贴图附在真实器物上。亮度保证路径和关键物件可辨。重做键鼠控制、碰撞子步进、阅读暂停、存档与返回标题，提供触屏移动和调查。

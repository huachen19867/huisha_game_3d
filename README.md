# 回煞

《回煞》是一款第一人称民俗悬疑游戏。七月十四，李明带着母亲的信回到老宅。信里叮嘱他端灯时拢住手，信封上盖着昨天的邮戳。母亲已经去世十年。

[在线游玩《回煞》3D](https://huachen19867.github.io/huisha_game_3d/) · [在线游玩 2D 封存版](https://huachen19867.github.io/huisha_game_AI/)

新游戏先播放从 2D 版移植的雨夜驾驶片头。下车时信就在外套内袋。按 B 拆信，去亮灯的值班室找周师傅，核对旧门牌，取备用钥匙进老宅。已有存档可以在标题页单独重看片头。山路的接驳通知、反光牌和上车点通向「归路」结局；厨房相册通向学校、医院与事故现场。

西厢从雨庭西墙的门洞进入。卧房楼梯通阁楼，柜后的修理间通地下储水间。修好厨房的秤之后，可以先翻相册，也可以去阁楼解下晾篮、回正厅守夜。要打开棺锁，还得把储水间的积水排掉。旧相册里的学校和医院可以先查，事故照片要从校服里找回。0.18 已解量水秤的存档继续保留事故记忆入口。

[村口实机画面](docs/village-night.jpg) · [值班室](docs/night-shift.jpg) · [父母卧房](docs/west-bedroom.jpg) · [阁楼](docs/attic.jpg) · [地下储水间](docs/cellar.jpg) · [量水秤](docs/kitchen-scale.jpg)

第一章可以在供桌借火，按 F 或屏幕上的“拢住灯火”遮风，把灯端到走廊尽头照出门闩的活扣。风从左边破窗进来，贴右墙也能避开。熄了可以用供烛重燃。归门字轮仍能单独打开同一扇门，之后接雨庭、厨房及三段记忆。

过了门槛，院门旁的纸人会提灯扫视石路。看见灯光扫到鞋边，可以站住等它转开，也可以借井身和廊檐遮住自己。被发现会回到门槛，已解机关与调查进度保留。走进右手边亮着灯的厨房，这一晚的脚步声就停在院子里。[雨庭游戏画面](docs/courtyard.jpg)

守夜灯与正厅模型在 [ThreeHouseScene.js](src/3d/ThreeHouseScene.js)，风口、开闩与存档兼容见 [ThreeStory.js](src/3d/ThreeStory.js)，提灯纸人的视线与声音提示由 [ThreeYardWatch.js](src/3d/ThreeYardWatch.js) 驱动。主线制作记录见 [技术日志](DEV_LOG.md)。

## 老宅与记忆

独立重新制作的第一人称民俗悬疑游戏。收到去世母亲的来信后，你回到雨夜旧宅。观察器物上的字迹，转动三位铜锁，再走进雨庭与厨房，用三升、五升提桶量出四升水，取出母亲没有寄出的家书，自己决定是否走出院门。

厨房柜边的相册连接“录取那年 / 病历之前 / 雨夜归途”三段记忆。主动翻入学校、医院和事故山路，观察日期、签字和物件，从两份已读原文中取出事实片段、排列先后，再选择解释提交推理。完整核对后，雨夜的救护灯前会出现新的去向选择。

本仓库只维护 3D。原 [2D 版本](https://github.com/huachen19867/huisha_game_AI) 已停止研发并保留成果。旧 3D 原型的布局、界面、交互和拼装家具已被替换；本版使用本地 glTF 中式家具、木地板与灰墙 PBR 材质，不依赖在线 CDN。

正厅的木格窗、学校和医院的窗都嵌在实际窗洞里，有墙厚、窗框和窗台；两处记忆使用不同深浅的玻璃。正厅窗外有石地、低墙和屋檐构成的侧院，供观察窗外空间，不是新增可走区域。窗洞不会让玩家穿出房间。窗墙按材质合并静态网格，沿用已有材质与本地 Three.js 工具，没有新增图片或模型依赖。

## 运行

本地运行需要 Node.js 18 或更新版本。Windows 双击 `StartGame.bat`，或在项目目录运行 `npm start`，然后访问 <http://127.0.0.1:8133>。无需安装 npm 依赖。关闭终端即可停止本地服务。

请通过本地服务或静态托管运行，直接双击 HTML 会被浏览器阻止加载模块和材质。

WASD 或方向键移动，双击 W 并按住第二下疾跑，也可按住 Shift。空格跳跃。靠近物件后用 E 或左键调查，再按 E、点返回或点面板外空白收起。B 打开背包，H 查看当前操作提示。J 打开手记，M 看地图，Esc 暂停并查看操作说明。触屏可连点两次「前」并按住疾跑，点「跳」跨过倒木，拖动画面转头。

按 M、点击 HUD“地图”或从暂停页进入探索地图。地图沿用实际房间尺寸，随走动记录空间；只标出已经观察过的器物和已知机关，不显示未知线索。颜色表示走过、已知事项待处理或已处理，不代表房间搜完。可以切换“查看范围”放大已到过的房间，点击下面的记录回查原文，再回到地图。地图不传送或替你调查。

位置箭头显示真实站位与朝向，近看机关时不会把镜头位置当成玩家位置。记忆空间分别记录，只能查看到过的空间；在记忆里查看老宅地图时，标的是厨房返回点。走过的空间随故事进度保存，旧存档根据已读记录补回对应地点，重新开始会清空。打开地图与原文均暂停探索，退出后继续。

标题的“游玩设置”和暂停页均可调整亮度、音量、鼠标/触屏各自的视角灵敏度与上下反转。关闭“点击场景后锁定鼠标”即可只用左键按住拖动；设备拒绝锁定时也能拖动。右键不会捕获鼠标，第二根触屏手指不会接管已有的转头手势。设置单独保存在 `huisha.3d.preferences.v1`，刷新、回标题和重新开始故事都会保留；“恢复默认设置”只重置这些偏好。浏览器拒绝保存时，当前页面仍可使用。

木地板与硬地面使用不同脚步，各有三个音效变体。转铜轮有金属反馈，松开门闩/压平秤盘有木与金属碰撞，翻纸和倒水也分开反馈。室内外雨声会渐变，进入学校/医院记忆后室外雨声淡出。声音样本来自 Kenney CC0、本地分发，仅在进入游戏后加载；详细来源与合成回退见 [声音说明](assets/audio/README.md)。

靠近并看向可以调查的器物后，圆形标记会落在器物的调查位置，屏幕下方显示标题；已观察的标记颜色减淡。屏幕外、背后和被遮挡的目标不提供调查提示，竖屏也需要真正转头看到物件。阅读和操作机关时隐藏调查标记。

供桌后的相框可以拿近观察。先主动揭开黑布，再按住画面拖动相框，或使用“翻到背面”；背字真正转到眼前后，“阅读背字”才可用。揭布、翻面和阅读是三个动作，揭布不会直接把背字写进手记。原文可摘取，回查手记后仍保持拿着相框时的朝向；“放回原处”或 Esc 恢复原站位与视角。旧存档中已读的相框内容继续保留。

调查归门字轮后，会近看场景里的实体机关。点击左、中、右铜轮，或按 1 / 2 / 3 转动；也可使用底部按钮。四个刻面随转鼓实际旋转，回查手记后仍停在机关前，Esc 退回原来的站位和朝向。压下门闩才判断答案，开门过程直接发生在场景中。机关操作布局单独维护在 `src/lock.css`。

解开字轮后，门闩先退开，绳端再从铜轮下落，随后门扇开始转动；三根红绳会松弛留在地面。门外补光随实际开门角度渐变。这个过程可以暂停，读取已解锁的存档或使用减少动态效果时直接恢复完成后的姿态，不重复播放松闩声。

卡住时可从手记或字轮旁选择“需要提示”。先给下一处观察方向，再解释已经读到的字迹；只有主动选择“直接查看字轮答案”才显示组合。提示不替你调查、转轮或开门。门扇向外开启，碰撞随实际角度转动；减少动态效果偏好下直接打开。

手记按地点整理，进入记忆后默认翻到当前这一处，也可切回全部已读记录。原文旁的“放入摘记”可保留两份全文并排对照，第三份不会覆盖已有选择；先移除一份即可更换。字轮和量水桌的“随手摘记”可以展开查看原文，不用退出机关视角。整理记忆时可主动把两份摘记放入草稿，再自行选择解释与提交；摘记不判定正确与否，也不会代替调查。摘记随独立 3D 存档恢复，重新开始会一并清空。

厨房量水桌有独立近看视角。点桶或按 1 / 2 选中三升桶、五升桶，再点击水缸添满、水槽倒空、秤盘放上五升桶；两桶互倒使用下方按钮。也可用 F 添满、X 倒空、P 倒入另一桶。水位实时显示，错误尝试不扣水、不清空进度；桌旁能回查手记与按需提示，Esc 退回原站位。五升桶恰好四升时，主动放上秤盘才会打开抽屉和院门。

试称时五升桶会提起、移到秤盘上，落下后才判断。秤盘下沉量和旁边的指针跟随水量，红刻线表示四升；偏轻或偏重时，桶稍后放回，水量保留。试称期间不能改桶内水量，仍可回查手记或退出。回查会暂停，落秤前退出会取消本次试称；正确落秤后的解锁进度保留。减少动态效果时跳过搬动，仍需主动试称。中途刷新保留水量，未落秤的尝试不计为解锁。

厨房桌下的铜索沿墙和檐廊连到院门，滑轮与门闩可以实际观察。压平秤盘后，铜索拉开门闩、绳头垂到门框旁，院门才开始转动。信跟着抽屉滑出，露出后才有调查提示；抽屉若占到玩家或原返回站位，会向前让开一点，避免放下机关后卡在抽屉内。中途刷新时也会在抽屉前就近恢复，保留朝向。阅读期间这些物件的动画暂停。

读到任意一段记忆中的记录后，可以从原文旁或手记里“整理记忆”。选取两份原文后，用“放入时间线”、上移、下移与“放回旁边”整理事实；没有明确日期的描述可留在旁边。片段只来自已读原文，不自动排序。两份选证、时间线和判断随草稿保存，错误或换选证均不清空；换选证后会提醒已有片段的来源是否还在当前选证中。摘记带入仅复制选证，排好顺序后仍需主动提交。旧存档已完成的推理继续有效；0.14 以前未完成的草稿保留选证与时间线，原解释需按更新后的事实问题重选，页面会说明。

打开记录、手记或地图时立即保存真实站位，整理期间刷新也能恢复。记忆内可以随时从门边或暂停菜单明确回到厨房，恢复翻相册前的站位与视角。正确推理后仍可留在原场景继续观察，不会被自动传回。

事故山路上的手机可以拿近查看。点击屏幕下方的“通话记录 / 录音资料”，或使用按钮及 1 / 2 切换页面，再主动选择“阅读并记下当前页”。拿起和换页不会直接把资料加入手记；只读通话页时，手记、摘记和时间线不会提前显示录音日期。录音页显示本地文件日期与录音文字，没有新增语音播放。两页都核对后仍须自己排列事实、选择解释并提交。回查手记/地图后返回手机保留页面，Esc 或“放回原处”恢复原站位；从记录页回厨房也会先放回手机。旧存档中已读过的整份手机记录兼容为两页已读，新档分别保存。

学校课桌上的录取通知和家长回执也可拿近、拖动和翻面。正面有日期与签字，背面分别是你写给自己的话和父亲的留言；转到眼前后，主动“阅读并记下这一面”才会收录。未读背面不会出现在手记或摘记中，未读正面也不能提供日期片段。只看日期还不足以判断父亲说过什么，提交前需要核对留言。回查手记或放大阅读会暂停翻动，回查后保持朝向，放回恢复纸张和玩家站位；旧整份已读记录按两面保留，新档分别保存。纸张具有轻微弯曲、折痕和受光字迹，不是悬浮在桌上的发光牌。

医院的初诊病历和复诊安排沿用同样的纸张观察。病历放在门诊桌上，复诊安排夹在轮椅旁的立板上，放回时各自恢复原姿态。核对初诊日期、复诊日期和患者签字，再翻看复诊安排背面的复诊/代取药办法；病历背面的后续治疗记录可自行决定是否阅读。三段推理现在核对的是先后、签字、通话方向与记录内容，不把孝顺、原谅或治愈保证当成标准答案；核对结果仍由原文支撑，去留结局仍须另行选择。

纸张与手机按“阅读并记下”后，原文直接展开在近看面板里，可以继续翻面、切页、放入摘记或整理记忆，不用逐页合上全文弹窗。需要大字时可主动“放大阅读”，仍能回到原来的物件朝向/页面。只显示当前已读的一面或页面，转到侧面、未读面或未读页会收起旧原文；放回物件和重新开始也清掉面板内容。每次记下内容时立即保存真实站位，不依赖放大弹窗或定时保存。

## 当前内容与验证

当前有正厅、走廊、雨庭、厨房、院外山路，以及三处可进出的 3D 记忆空间。实体字轮、量水秤与原文推理共同推进探索；可以在山路选择“归路 / 余温”，也可以完整核对三段记忆后在救护灯前选择“破茧 / 回煞”。所有结局都须明确选择。旧首章和量水存档可以继续；观察、机关、记忆位置/返回点、推理草稿和去留使用独立的 3D 存档键保存，新字段安全补全。追逐与复杂角色动画尚未制作。

运行 `npm run verify` 检查六份真实 glTF、射线、路线可达性、机关流程、量水守恒、中途/旧存档恢复、记忆区域隔离、两份选证/解释提交、草稿、返回点和四种主动结局。量水近看核对六种视口的投影、点选和控制区预留范围；没有运行 DOM 布局或浏览器。该检查不能证明真实 WebGL 画质、原生下拉控件、手机操作或最终游玩体验。此前浏览器启动被审批拦截，本轮未重试或绕过；画面与实机手感仍未验收。

开发者可先运行 `npm ci --ignore-scripts`，再用 `npm run verify:ui` 检查实际入口与界面的 DOM 事件链：字轮/量水按钮、手记回返、已读选证、错误提交、草稿重新加载、三段记忆、四种去向和重开确认。该命令使用固定版本 jsdom 26.1.0 和 Node VM Modules，依赖锁定在 package-lock.json；渲染启动与场景同步使用替身，对话框开合使用 shim，没有创建浏览器或 WebGL，也没有验证原生模态、下拉默认行为、布局、触屏、指针锁或音频。jsdom 只用于开发检查，正常 `npm start` 仍无需安装依赖。

0.3.1 减少调查开销：提示按约 20 Hz 扫描，调查键即时复查；只对当前空间、可见、确实遮挡且不属于目标自己的几何执行射线。优先判断最可能的目标，被挡住再检查下一个；暂停与记忆切换即时刷新。红绳改为直接更新，记忆环境只在切换时更新，避免重复遍历与赋值。这里验证的是查询次数与语义，未测得真实 WebGL 帧率。加载过程出现的材质错误会保留在标题提示里。

## 文件索引

入口为 `index.html`，界面与生命周期在 `src/main.mjs` / `src/style.css`，两套机关界面分别使用 `src/lock.css` / `src/water.css`。`src/3d/ThreeHouseScene.js` 搭建场景并加载模型，`ThreeHouseMap.js` 描述正厅；`ThreeCourtyardMap.js` 合并雨庭/厨房/山路的可走区域、碰撞与线索，`ThreeCourtyard.js` 建立实体量水装置、院门、近看相机与动画，复用已下载的真实中式条案和柜子。`ThreeControls.js` 负责移动与两扇转动门的碰撞，`ThreeInteraction.js` 负责视线调查，`ThreeStory.js` 管理两种机关与存档，`ThreeAudio.js` 合成环境声与反馈。`tools/serve.mjs` 提供本地静态服务。

记忆部分由 `ThreeMemoryMap.js` 定义空间、原文和推理条件，`ThreeMemoryScenes.js` 布置课桌/椅、轮椅与事故护栏等真实场景，`ThreeMemoryJournal.js` 管理原生选证与解释控件，`ThreeMemoryTimeline.js` 管理事实卡片、顺序和操作后的焦点，样式在 `src/memory.css`。主世界与记忆只显示当前空间，移动和调查也按当前空间限制；未解锁或异常的存档位置会安全回退。

`ThreeWindowWall.js` 共用窗洞墙体、窗框/窗格和玻璃的建模。墙段使用连续 UV，四段墙体合为一份网格，窗框/窗条合为另一份；玻璃单独保留透明绘制，不投实心阴影。合并复用现有 `vendor/BufferGeometryUtils.mjs` 的 `mergeGeometries`，主入口注入到场景命名空间；替换后的临时几何及时释放，窗材质随场景统一释放。

`ThreePhone.js` / `src/phone.css` 管理手机实体、按页面更新的屏幕文字、屏幕 UV 点选与近看取景；`ThreeMemoryScenes` 将手机放在事故石块上。页面内容在 `ThreeMemoryMap` 的 `PHONE_PAGES`，`ThreeStory.phoneViews` 保存已主动阅读的页面，`phoneText()` 为手记提供当前已知原文，`knowsFact()` 同时校验记录与对应页面。未读页面不进入时间线，旧整份观察迁移为两页；标题、记录页及选证继续使用同一个手机记录 id。

`ThreeDocument.js` / `src/document.css` 共用学校与医院四张纸的正反面、弯曲几何、翻转/拖动和取景，按所属记忆分别建模并保存原放置朝向。内容来自 `ThreeMemoryMap.DOCUMENTS`，`ThreeStory.documentViews` 按记录保存已读面，`documentText()` 提供已知原文；`knowsFact()` 校验日期来自已经读过的正面，`MEMORY_CASES.requiredFaces` 明确每段核对所需的面。Canvas 字迹纹理只在创建时绘制，学校纸张与医疗表格使用不同色调。`ThreeHouseScene` 统一保存近看前站位和退出恢复，主入口管理按钮与当前可读面。

事实问题的版本由 `ThreeStory.reasoningRevision` 维护。旧问题的未提交选择不自动套入新选项，`questionChanged` 提醒在重新选择前保留，选证/时间线不动；已完成判断继续有效。0.13 存档虽已有学校的 documentViews，医院整份记录仍按当时已读的内容补齐正反面，避免把新增纸面字段误当成丢失观察。

`src/main.mjs` 的 `updateObjectReading()` 共用纸张/手机的已读原文面板，样式在 `src/lock.css` 的 inspection-reading。使用原生 details、现有摘记按钮和同一个记忆推理入口；放大阅读沿用原 dialog，未新增运行库、存档字段或另一套选证状态。切换时清理失效原文及按钮，必要时把焦点移回可用的翻面/页面按钮；离开近看清空两处面板。

`ThreeInteraction` 在模型载入完成后建立各空间遮挡物索引，门扇旋转和物件显隐会直接生效；若后续在运行中增删几何或改变其所属空间，需要调用 `rebuildOccluders()` 重建索引。当前游戏的机关只移动或隐藏已有几何。

`tools/verify_ui.mjs` 通过 VM 直接加载现有 `src/main.mjs`、故事、控制、调查和记忆界面模块，以 jsdom 的 click/change/keydown 事件驱动它们；没有复制一套推理或存档实现。`node_modules/` 不入库，开发依赖可从锁文件恢复；来源和许可见参考索引。

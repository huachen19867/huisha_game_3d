# 回煞 3D · 归门与余温

“不要再替我守灯。门闩在你那边。”

独立重新制作的第一人称民俗悬疑游戏。收到去世母亲的来信后，你回到雨夜旧宅。观察器物上的字迹，转动三位铜锁，再走进雨庭与厨房，用三升、五升提桶量出四升水，取出母亲没有寄出的家书，自己决定是否走出院门。

厨房柜边的相册连接“录取那年 / 病历之前 / 雨夜归途”三段记忆。主动翻入学校、医院和事故山路，观察日期、签字和物件，再用两份已读原文与一个解释提交推理。完整核对后，雨夜的救护灯前会出现新的去向选择。

本仓库只维护 3D。原 [2D 版本](https://github.com/huachen19867/huisha_game_AI) 已停止研发并保留成果。旧 3D 原型的布局、界面、交互和拼装家具已被替换；本版使用本地 glTF 中式家具、木地板与灰墙 PBR 材质，不依赖在线 CDN。

## 运行

需要 Node.js 18 或更新版本。Windows 双击 `StartGame.bat`，或在项目目录运行 `npm start`，然后访问 <http://127.0.0.1:8133>。无需安装 npm 依赖。关闭终端即可停止本地服务。

请通过本地服务或静态托管运行，直接双击 HTML 会被浏览器阻止加载模块和材质。

WASD / 方向键移动，鼠标拖动或点击画面锁定视角，Shift 快走，E 调查，J 手记，Esc 暂停。触屏可使用左下方向键移动、拖动画面转头、点击调查提示。阅读时暂停移动，合上后继续；可在暂停中调整亮度和声音。

标题的“游玩设置”和暂停页均可调整亮度、音量、鼠标/触屏各自的视角灵敏度与上下反转。关闭“点击场景后锁定鼠标”即可只用左键按住拖动；设备拒绝锁定时也能拖动。右键不会捕获鼠标，第二根触屏手指不会接管已有的转头手势。设置单独保存在 `huisha.3d.preferences.v1`，刷新、回标题和重新开始故事都会保留；“恢复默认设置”只重置这些偏好。浏览器拒绝保存时，当前页面仍可使用。

木地板与硬地面使用不同脚步，各有三个音效变体。转铜轮有金属反馈，松开门闩/压平秤盘有木与金属碰撞，翻纸和倒水也分开反馈。室内外雨声会渐变，进入学校/医院记忆后室外雨声淡出。声音样本来自 Kenney CC0、本地分发，仅在进入游戏后加载；详细来源与合成回退见 [声音说明](assets/audio/README.md)。

靠近并看向可以调查的器物后，圆形标记会落在器物的调查位置，屏幕下方显示标题；已观察的标记颜色减淡。屏幕外、背后和被遮挡的目标不提供调查提示，竖屏也需要真正转头看到物件。阅读和操作机关时隐藏调查标记。

供桌后的相框可以拿近观察。先主动揭开黑布，再按住画面拖动相框，或使用“翻到背面”；背字真正转到眼前后，“阅读背字”才可用。揭布、翻面和阅读是三个动作，揭布不会直接把背字写进手记。原文可摘取，回查手记后仍保持拿着相框时的朝向；“放回原处”或 Esc 恢复原站位与视角。旧存档中已读的相框内容继续保留。

调查归门字轮后，会近看场景里的实体机关。点击左、中、右铜轮，或按 1 / 2 / 3 转动；也可使用底部按钮。四个刻面随转鼓实际旋转，回查手记后仍停在机关前，Esc 退回原来的站位和朝向。压下门闩才判断答案，开门过程直接发生在场景中。机关操作布局单独维护在 `src/lock.css`。

卡住时可从手记或字轮旁选择“需要提示”。先给下一处观察方向，再解释已经读到的字迹；只有主动选择“直接查看字轮答案”才显示组合。提示不替你调查、转轮或开门。门扇向外开启，碰撞随实际角度转动；减少动态效果偏好下直接打开。

手记按地点整理，进入记忆后默认翻到当前这一处，也可切回全部已读记录。原文旁的“放入摘记”可保留两份全文并排对照，第三份不会覆盖已有选择；先移除一份即可更换。字轮和量水桌的“随手摘记”可以展开查看原文，不用退出机关视角。整理记忆时可主动把两份摘记放入草稿，再自行选择解释与提交；摘记不判定正确与否，也不会代替调查。摘记随独立 3D 存档恢复，重新开始会一并清空。

厨房量水桌有独立近看视角。点桶或按 1 / 2 选中三升桶、五升桶，再点击水缸添满、水槽倒空、秤盘放上五升桶；两桶互倒使用下方按钮。也可用 F 添满、X 倒空、P 倒入另一桶。水位实时显示，错误尝试不扣水、不清空进度；桌旁能回查手记与按需提示，Esc 退回原站位。五升桶恰好四升时，主动放上秤盘才会打开抽屉和院门。

读到任意一段记忆中的记录后，可以从原文旁或手记里“整理记忆”。两份选证与解释会作为未提交草稿保存，错误不清空；读完和提示都不自动完成推理。记忆内可以随时从门边或暂停菜单明确回到厨房，恢复翻相册前的站位与视角。正确推理后仍可留在原场景继续观察，不会被自动传回。

## 当前内容与验证

当前有正厅、走廊、雨庭、厨房、院外山路，以及三处可进出的 3D 记忆空间。实体字轮、量水秤与原文推理共同推进探索；可以在山路选择“归路 / 余温”，也可以完整核对三段记忆后在救护灯前选择“破茧 / 回煞”。所有结局都须明确选择。旧首章和量水存档可以继续；观察、机关、记忆位置/返回点、推理草稿和去留使用独立的 3D 存档键保存，新字段安全补全。追逐与复杂角色动画尚未制作。

运行 `npm run verify` 检查六份真实 glTF、射线、路线可达性、机关流程、量水守恒、中途/旧存档恢复、记忆区域隔离、两份选证/解释提交、草稿、返回点和四种主动结局。量水近看核对六种视口的投影、点选和控制区预留范围；没有运行 DOM 布局或浏览器。该检查不能证明真实 WebGL 画质、原生下拉控件、手机操作或最终游玩体验。此前浏览器启动被审批拦截，本轮未重试或绕过；画面与实机手感仍未验收。

开发者可先运行 `npm ci --ignore-scripts`，再用 `npm run verify:ui` 检查实际入口与界面的 DOM 事件链：字轮/量水按钮、手记回返、已读选证、错误提交、草稿重新加载、三段记忆、四种去向和重开确认。该命令使用固定版本 jsdom 26.1.0 和 Node VM Modules，依赖锁定在 package-lock.json；渲染启动与场景同步使用替身，对话框开合使用 shim，没有创建浏览器或 WebGL，也没有验证原生模态、下拉默认行为、布局、触屏、指针锁或音频。jsdom 只用于开发检查，正常 `npm start` 仍无需安装依赖。

0.3.1 减少调查开销：提示按约 20 Hz 扫描，调查键即时复查；只对当前空间、可见、确实遮挡且不属于目标自己的几何执行射线。优先判断最可能的目标，被挡住再检查下一个；暂停与记忆切换即时刷新。红绳改为直接更新，记忆环境只在切换时更新，避免重复遍历与赋值。这里验证的是查询次数与语义，未测得真实 WebGL 帧率。加载过程出现的材质错误会保留在标题提示里。

## 文件索引

入口为 `index.html`，界面与生命周期在 `src/main.mjs` / `src/style.css`，两套机关界面分别使用 `src/lock.css` / `src/water.css`。`src/3d/ThreeHouseScene.js` 搭建场景并加载模型，`ThreeHouseMap.js` 描述正厅；`ThreeCourtyardMap.js` 合并雨庭/厨房/山路的可走区域、碰撞与线索，`ThreeCourtyard.js` 建立实体量水装置、院门、近看相机与动画，复用已下载的真实中式条案和柜子。`ThreeControls.js` 负责移动与两扇转动门的碰撞，`ThreeInteraction.js` 负责视线调查，`ThreeStory.js` 管理两种机关与存档，`ThreeAudio.js` 合成环境声与反馈。`tools/serve.mjs` 提供本地静态服务。

记忆部分由 `ThreeMemoryMap.js` 定义空间、原文和推理条件，`ThreeMemoryScenes.js` 布置课桌/椅、轮椅与事故护栏等真实场景，`ThreeMemoryJournal.js` 管理原生选证与解释控件，样式在 `src/memory.css`。主世界与记忆只显示当前空间，移动和调查也按当前空间限制；未解锁或异常的存档位置会安全回退。

`ThreeInteraction` 在模型载入完成后建立各空间遮挡物索引，门扇旋转和物件显隐会直接生效；若后续在运行中增删几何或改变其所属空间，需要调用 `rebuildOccluders()` 重建索引。当前游戏的机关只移动或隐藏已有几何。

`tools/verify_ui.mjs` 通过 VM 直接加载现有 `src/main.mjs`、故事、控制、调查和记忆界面模块，以 jsdom 的 click/change/keydown 事件驱动它们；没有复制一套推理或存档实现。`node_modules/` 不入库，开发依赖可从锁文件恢复；来源和许可见参考索引。

0.4.0 的手记与机关旁摘记由 `src/3d/ThreeEvidenceJournal.js` / `src/evidence.css` 管理，摘记字段的校验与保存仍归 `ThreeStory`。DOM 检查覆盖地点筛选、未观察内容隔离、主动摘取/移除、机关旁原文、摘记转草稿、刷新恢复与重开清理；没有验证浏览器布局和实际画面。

0.4.1 在 `ThreeInteraction` 中把目标点投影到当前相机，过滤屏幕外候选；`src/exploration.css` 管理屏幕标记。标记逐帧跟随投影，遮挡扫描仍约 20 Hz，按 E 即时复查。六种横竖视口、转头、观察后状态和暂停的数学/事件检查已通过，未测得实际设备帧率或画面可辨性。

0.5.0 的设备偏好在 `ThreePreferences.js`，标题/暂停设置由 `ThreeSettings.js` / `src/settings.css` 呈现，`ThreeControls` 实时读取偏好。`ThreeAudio` 管理音效样本、合成反馈和声区过渡；声音来源在 `assets/audio/sources.json`，原始许可随音效分发。检查覆盖设置独立保存、重开保留、鼠标/触屏速度和反转、锁定不可用时拖动、声区/脚步和声音加载生命周期，没有真实设备输入、音频解码或试听验收。

0.6.0 的实体相框在 `ThreePortrait.js` / `src/portrait.css`。照片为内置 image_gen 生成的虚构人物资源 `assets/art/mother-portrait.png`，完整提示词、来源与 SHA-256 在同名 `.source.json`；不是真人照片或商业游戏素材。几何检查覆盖正反面、掀布、六视口、阅读暂停和站位/投影恢复，界面检查覆盖拖动、翻面后主动阅读、手记回返与存档兼容。没有真实 WebGL 的材质/照片观感、手势或完整实玩验收。
